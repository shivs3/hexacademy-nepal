# Hexacademy Nepal — frontend

Next.js 16 App Router app. Setup, commands and architecture are documented in the repository root: [../README.md](../README.md) and [../docs/architecture.md](../docs/architecture.md).

Before changing framework-level code, read the bundled Next.js docs in `node_modules/next/dist/docs/` (see `AGENTS.md`). Next 16 differs from older versions; for example, middleware is now `proxy.ts` and request APIs are async.
