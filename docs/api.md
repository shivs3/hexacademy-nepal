# API

Base path: `/api/v1/`. The OpenAPI schema is generated by drf-spectacular. In development it's served at `/api/schema/` with Swagger UI at `/api/docs/`; CI validates it with `spectacular --validate --fail-on-warn`. Those endpoints are not mounted in production.

## Conventions

- **Auth:** session cookie. Unsafe methods require the `X-CSRFToken` header set to the `hx_csrftoken` cookie value. Call `GET /auth/csrf/` once if the cookie is missing.
- **Trailing slashes:** every path ends in `/`.
- **Errors:** always this shape:
  ```json
  { "error": { "code": "validation_error", "message": "Invalid input.", "details": { "email": ["…"] } } }
  ```
  Codes: `validation_error`, `not_authenticated`, `permission_denied`, `not_found`, `throttled`, `invalid_credentials`, `conflict`, plus domain-specific codes. With session auth, anonymous requests receive **403** `not_authenticated`, not 401.
- **Pagination:** `?page=&page_size=` (max 100). Response:
  `{ count, page, page_size, total_pages, next, previous, results }`.
- **Filtering/search/ordering:** `?search=`, `?ordering=-field`, plus endpoint-specific filters.
- **Request IDs:** send `X-Request-ID` (otherwise one is generated). It's echoed in the response and written to logs and audit entries.
- **Money:** integer minor units (paisa) with an explicit currency. Never floats.
- **Times:** ISO 8601 with offset. The server timezone is Asia/Kathmandu (+05:45).

## Accounts (M1)

| Method | Path | Permission | Notes |
| --- | --- | --- | --- |
| GET | `/auth/csrf/` | public | Sets the CSRF cookie and returns `{csrf_token}` |
| POST | `/auth/register/` | public, throttled 5/min | Creates a student, signs in, sends a verification email. 201 + current user |
| POST | `/auth/login/` | public, throttled 10/min per IP and per email | Generic `invalid_credentials` error. Inactive accounts get the same error |
| POST | `/auth/logout/` | authenticated | 204 |
| POST | `/auth/password-reset/` | public, 5/hour | Always 202, never reveals whether the account exists |
| POST | `/auth/password-reset/confirm/` | public, 5/hour | `{uid, token, new_password}` → 204. Token is single-use and expires in 2h |
| POST | `/auth/verify-email/` | public, 10/hour | `{token}`. Signed token, expires in 3 days |
| POST | `/auth/verify-email/resend/` | authenticated, 10/hour | 202 |
| GET/PATCH | `/users/me/` | authenticated | Current user incl. roles, permissions and nested `profile`. Email is read-only |
| POST | `/users/me/password/` | authenticated | `{current_password, new_password}` → 204. Other sessions are invalidated |
| GET | `/admin/roles/` | `accounts.view_user_directory` | Assignable roles |
| GET | `/admin/users/` | `accounts.view_user_directory` | `?search= ?role= ?is_active= ?ordering=` |
| GET | `/admin/users/{id}/` | `accounts.view_user_directory` | |
| POST | `/admin/users/{id}/status/` | `accounts.manage_user_status` | `{is_active}`. Cannot target yourself or a superuser (unless you are one) |
| PUT | `/admin/users/{id}/roles/` | `accounts.assign_roles` | `{roles: [...]}`. `super_admin` is rejected |

## CMS (M2)

### Public

None of these endpoints ever return drafts, archived content, scheduled posts before their time, or hidden menu items.

| Method | Path | Notes |
| --- | --- | --- |
| GET | `/site-settings/` | Branding, contact, social, footer, the announcement (only while inside its window), SEO defaults |
| GET | `/menus/{header\|footer\|legal}/` | Visible items only, two levels. Page links resolve to the page's current path, and links to unpublished pages are dropped |
| GET | `/home-page/` | The published version of the home page |
| GET | `/pages/{slug}/` | The published version. 404 for drafts and archived pages |
| GET | `/blog/posts/` | `?category=<slug>&page=`. Published posts whose `published_at` has passed |
| GET | `/blog/posts/{slug}/` | |
| GET | `/blog/categories/` | |
| GET | `/seo/sitemap/` | Paths and last-modified dates for the Next sitemap. Pages marked `noindex` are excluded |
| POST | `/newsletter/subscribe/` | `{email, consent: true, source}`, throttled 10/hour. Always 202, so it never reveals whether the email is already subscribed |

### Staff

| Method | Path | Permission |
| --- | --- | --- |
| GET | `/admin/cms/overview/` | any of manage_pages, manage_blog, manage_media |
| GET | `/admin/cms/section-types/` | manage_pages. Field descriptors drive the section builder |
| GET/POST | `/admin/cms/pages/` | manage_pages. `?search= ?status= ?ordering=` |
| GET/PATCH/DELETE | `/admin/cms/pages/{id}/` | manage_pages. A PATCH saves the draft and records a version when the content changed. Deleting a published page or the home page is refused |
| POST | `…/{id}/publish/` `{version?}`, `…/schedule/` `{publish_at, version?}`, `…/cancel-schedule/`, `…/unpublish/`, `…/archive/`, `…/unarchive/`, `…/make-home/` | manage_pages **and** publish_pages |
| POST | `…/{id}/duplicate/`, `…/{id}/restore/` `{version}` | manage_pages |
| GET | `…/{id}/versions/` (paginated), `…/{id}/preview/?version=` | manage_pages |
| GET/POST | `/admin/cms/media/` | List: any CMS editing permission. Upload (multipart `file`, `title`, `alt_text`): manage_media |
| GET/PATCH/DELETE | `/admin/cms/media/{id}/` | PATCH and DELETE: manage_media. A PATCH may change only `title` and `alt_text` |
| GET/PATCH | `/admin/cms/site-settings/` | manage_site_settings |
| GET | `/admin/cms/menus/` | manage_menus |
| GET/PUT | `/admin/cms/menus/{location}/` | manage_menus. A PUT replaces the whole tree `{title, items: [{label, page?, url?, open_in_new_tab, is_visible, children: […]}]}`, with at most 60 links |
| GET/POST | `/admin/cms/blog/posts/` | manage_blog. `?search= ?status=` |
| GET/PATCH/DELETE | `/admin/cms/blog/posts/{id}/` | manage_blog. Editing a **published** post also needs publish_blog. Deleting a published post is refused |
| POST | `…/{id}/publish/` `{publish_at?}`, `…/unpublish/` (back to draft, which also cancels a schedule), `…/archive/` | manage_blog **and** publish_blog |
| GET | `…/{id}/preview/` | manage_blog |
| GET/POST/PATCH/DELETE | `/admin/cms/blog/categories/` | manage_blog (not paginated) |
| GET | `/admin/cms/blog/authors/` | manage_blog. Staff accounts that can be named as an author |
| GET | `/admin/cms/newsletter/` | view_newsletter_subscribers. `?state=active\|unsubscribed ?search=` |
| GET | `/admin/cms/newsletter/export/` | view_newsletter_subscribers. CSV of active subscribers, audited, with cells escaped against formula injection |

Validation errors in nested data use the standard envelope with nested `details`, for example `{"items": [{}, {"children": [{}, {"url": ["…"]}]}]}`. The frontend flattens these into dotted keys such as `items.1.children.1.url`.
